# LAWZ - Legal Consultation & Lawyer Directory

**LAWZ** is a specialized platform designed to bridge the gap between legal professionals and clients. It provides a centralized directory where users can discover lawyers, book consultations (online or in-person), and engage in legal discussions through a community-driven comment system.

**Live Demo:** [lawz.vercel.app]([https://www.lawz.vercel.app](https://lawz.vercel.app/))

## ⚖️ About The Project

LAWZ was built to simplify the process of finding legal representation. Whether a user needs immediate online advice or a formal face-to-face meeting, the platform provides the tools to connect with the right legal expert based on their profile, specialization, and community feedback.

### Key Features

* **Lawyer Onboarding:** Dedicated registration for legal professionals to build detailed profiles including expertise, experience, and contact details.
* **Smart Search:** Users can filter and find lawyers based on their specific case requirements.
* **Multi-Channel Consultation:** Supports three primary interaction types:
* **Case Handling:** Direct engagement for long-term legal representation.
* **Online Consultation:** Virtual meetings for quick legal advice.
* **Meet Up:** Scheduling physical appointments.


* **Engagement System:** Integrated commenting system on profiles and posts, allowing for transparency and community interaction between lawyers and users.
* **Responsive Design:** Fully optimized for desktop, tablet, and mobile viewing.

## 🛠️ Installation & Setup

To run this project locally, follow these steps:

1. **Clone the repository:**
```bash
git clone https://github.com/your-username/lawz.git

```


2. **Navigate to the project directory:**
```bash
cd lawz

```


3. **Install dependencies:**
```bash
npm install
# or
yarn install

```


4. **Set up environment variables:**
Create a `.env.local` file in the root directory and add your necessary API keys (Database, Auth, etc.).
5. **Run the development server:**
```bash
npm run dev
# or
yarn dev

```


6. **Open in browser:**
Visit [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000) to see the application.
